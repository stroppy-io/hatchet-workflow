# Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the cross-tenant operator surface — `AdminService` (tenant/user CRUD) and `BinaryCacheAdminService` (artifact prewarm/list/evict + upload flow).

**Architecture:** One service `internal/domain/services/admin/`. Middleware adds a `RequirePlatformAdmin` interceptor that checks the JWT carries `platform_role=ADMIN` claim. Admin endpoints bypass tenant resolution. `AdminService.*` delegates to the existing IAM service's underlying repos rather than re-implementing CRUD (DRY: same domainerr, same hashing, same uniqueness checks). `BinaryCacheAdminService` writes the `binary_artifacts` table consumed by `ops.BinaryCacheService.Resolve` from Plan 06. `Prewarm` accepts a list of `(package_id, target_region)` pairs, validates the source package exists in S3, and inserts/updates artifact rows pointing at the target-region S3 mirror (mirror copy happens via S3 server-side `CopyObject`).

**Tech Stack:** Connect interceptor for platform-admin role, ratel repos on `iampb.Users`, `iampb.Tenants`, `opspb.BinaryArtifacts`, `internal/infrastructure/s3` server-side copy + presign for uploads.

**Prerequisites:** Plans 01-06 merged. IAM service exposes Go-level methods (`CreateUserRaw`, `DeleteUserHard`, etc.) on its `Service` struct that admin can call without going through the user-facing endpoints.

```go
func WrapPlatformAdmin(next connect.UnaryFunc, verifier JWTVerifier) connect.UnaryFunc {
	return func(ctx context.Context, req connect.AnyRequest) (connect.AnyResponse, error) {
		tok := strings.TrimPrefix(req.Header().Get("Authorization"), "Bearer ")
		claims, err := verifier.Verify(tok)
		if err != nil { return nil, connect.NewError(connect.CodeUnauthenticated, err) }
		if claims.PlatformRole != iampb.PlatformRole_PLATFORM_ROLE_ADMIN {
			return nil, connect.NewError(connect.CodePermissionDenied, errors.New(errorspb.Code_PERMISSION_DENIED.String()))
		}
		return next(WithPlatformAdmin(ctx, claims.UserId), req)
	}
}
```

```go
type BinaryCacheAdminService struct {
	artRepo *repository.ProtoRepository[opspb.BinaryArtifactAlias, ...]
	pkgRepo *repository.ProtoRepository[catalogpb.PackageAlias, ...]
	tx      pgtx.TxManager
	s3      S3Mirror
}

func (s *BinaryCacheAdminService) Prewarm(ctx context.Context, req *adminpb.PrewarmRequest) (*opspb.BinaryArtifact_List, error) {
	return pgtx.WithSerializableRet(ctx, s.tx, func(ctx context.Context) (*opspb.BinaryArtifact_List, error) {
		out := &opspb.BinaryArtifact_List{}
		for _, pid := range req.PackageIds {
			pkg, err := s.pkgRepo.FindByID(ctx, pid.GetValue())
			if err != nil { return nil, domainerr.FromPg(err) }
			for _, region := range req.TargetRegions {
				targetBucket := "stroppy-" + region
				targetKey := "artifacts/" + pkg.S3Key
				if err := s.s3.Copy(ctx, pkg.S3Bucket, pkg.S3Key, targetBucket, targetKey); err != nil {
					return nil, err
				}
				art := &opspb.BinaryArtifact{
					Id: &opspb.BinaryArtifactId{Value: ids.NewULID()},
					PackageId: pid, Region: region,
					Bucket: targetBucket, Key: targetKey,
					Sha256: pkg.Sha256, Format: pkg.ArtifactFormat,
					CreatedAt: timestamppb.Now(),
				}
				if err := s.artRepo.Upsert(ctx, art, /*conflict on*/ "package_id,region"); err != nil {
					return nil, domainerr.FromPg(err)
				}
				out.Items = append(out.Items, art)
			}
		}
		return out, nil
	})
}

func (s *BinaryCacheAdminService) EvictArtifact(ctx context.Context, id *opspb.BinaryArtifactId) (*opspb.BinaryArtifact, error) {
	art, err := s.artRepo.FindByID(ctx, id.GetValue())
	if err != nil { return nil, domainerr.FromPg(err) }
	if err := s.s3.Delete(ctx, art.Bucket, art.Key); err != nil { return nil, err }
	if err := s.artRepo.Delete(ctx, id.GetValue()); err != nil { return nil, domainerr.FromPg(err) }
	return art, nil
}
```

## Acceptance criteria

- All `AdminService` RPCs reject non-admin JWTs with `PERMISSION_DENIED` and accept admin JWTs.
- `CreateTenant` produces tenant + owner user + member(role=ADMIN) atomically; failure rolls all three back.
- `DeleteTenantHard` removes all dependent rows (users-only-in-this-tenant excluded — only members are removed, users live across tenants).
- `ResetUserPassword` revokes all refresh tokens (forces re-login on all devices).
- `BinaryCacheAdminService.Prewarm` performs S3 server-side copy and `UPSERT`s artifact row per (package_id, region).
- `EvictArtifact` deletes both S3 object and DB row; idempotent re-call returns `NOT_FOUND`.
- Initial bootstrap creates platform admin from `features.initial_admin_email` + `INITIAL_ADMIN_PASSWORD` env var on first-ever start.
